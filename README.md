# 詞中天地｜宋詞作品欣賞

A static interactive Song-dynasty poetry exhibit. The site uses plain HTML, CSS, and JavaScript; there is no build step.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site from the `main` branch. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. After the first successful workflow run, GitHub will show the public Pages URL in the Actions deployment environment.
